# String Validation for Grammar S → 0S0 | A, A → 1A | ε

## 📌 Project Overview

This project implements a **C program** to check whether a given binary string belongs to the grammar:

```
S → 0S0 | A
A → 1A | ε
```

The grammar generates strings with an **equal number of `0`s at the beginning and end**, and **any number of `1`s in the middle** (including zero). The program validates the input string and determines whether it belongs to the language generated by the grammar.

---

## 🎯 Aim

To write and execute a C program to check whether a given string belongs to the grammar:

```
S → 0S0 | A
A → 1A | ε
```

---

## 📖 Theory

Given Grammar:

```
S → 0S0 | A
A → 1A | ε
```

### Explanation

- The production `A → 1A | ε` generates zero or more `1`s.
- The production `S → 0S0` adds one `0` at the beginning and one `0` at the end of the string.
- Therefore, every valid string contains:
  - Equal numbers of leading and trailing `0`s.
  - Only `1`s in the middle.

### Language Generated

```
L = { 0ⁿ1ᵐ0ⁿ | n ≥ 0, m ≥ 0 }
```

### Accepted Strings

- ε
- 1
- 11
- 1111
- 00
- 0110
- 01110
- 001100
- 000111000

### Rejected Strings

- 001110
- 1001
- 101
- 1100
- 01010

---

## ⚙️ Algorithm

1. Start the program.
2. Read the input binary string.
3. Count the number of leading `0`s.
4. Count the number of trailing `0`s.
5. Compare both counts.
6. If they are not equal, reject the string.
7. Check whether the remaining middle characters are all `1`s.
8. If true, accept the string; otherwise, reject it.
9. Stop the program.

---

## 💻 Source Code

```c
#include <stdio.h>
#include <string.h>

int main()
{
    char str[100];
    int len, left = 0, right = 0, i;

    printf("Enter the string: ");
    scanf("%s", str);

    len = strlen(str);

    /* Count leading zeros */
    i = 0;
    while(i < len && str[i] == '0')
    {
        left++;
        i++;
    }

    /* Count trailing zeros */
    i = len - 1;
    while(i >= 0 && str[i] == '0')
    {
        right++;
        i--;
    }

    if(left != right)
    {
        printf("String Rejected\n");
        return 0;
    }

    /* Check that the middle contains only 1's */
    for(i = left; i < len - right; i++)
    {
        if(str[i] != '1')
        {
            printf("String Rejected\n");
            return 0;
        }
    }

    printf("String Accepted\n");

    return 0;
}
```

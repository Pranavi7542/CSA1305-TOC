# String Validation for Context-Free Grammar (CFG) S → A101A, A → 0A | 1A | ε

## 📌 Project Overview

This project implements a **C program** to check whether a given binary string belongs to the language defined by the **Context-Free Grammar (CFG)**:

```
S → A101A
A → 0A | 1A | ε
```

The grammar generates all binary strings that **contain the substring `101`** at least once. Since `A` can generate any binary string (including the empty string), the program checks whether the input string contains the substring **`101`** and consists only of binary digits (`0` and `1`).

---

## 🎯 Aim

To write and execute a C program to check whether a given string belongs to the language defined by the Context-Free Grammar (CFG):

```
S → A101A
A → 0A | 1A | ε
```

---

## 📖 Theory

Given Grammar:

```
S → A101A
A → 0A | 1A | ε
```

### Explanation

- The production `A → 0A | 1A | ε` generates **any binary string**, including the empty string.
- The production `S → A101A` requires every valid string to contain the substring **`101`**.
- Therefore, any binary string containing `101` belongs to the language generated by the grammar.

### Language Generated

```
L = { x101y | x, y ∈ {0,1}* }
```

where `x` and `y` are any binary strings (including the empty string).

### Accepted Strings

- 101
- 0101
- 1010
- 11011
- 0010100
- 111010111

### Rejected Strings

- 000
- 111
- 010
- 1000
- 1100

---

## ⚙️ Algorithm

1. Start the program.
2. Read the input binary string.
3. Check whether every character is either `0` or `1`.
4. Search for the substring `101`.
5. If the substring is found, accept the string.
6. Otherwise, reject the string.
7. Stop the program.

---

## 💻 Source Code

```c
#include <stdio.h>
#include <string.h>

int main()
{
    char str[100];
    int i, len, found = 0;

    printf("Enter the binary string: ");
    scanf("%s", str);

    len = strlen(str);

    /* Check for valid binary string */
    for(i = 0; i < len; i++)
    {
        if(str[i] != '0' && str[i] != '1')
        {
            printf("String Rejected\n");
            return 0;
        }
    }

    /* Search for substring 101 */
    for(i = 0; i <= len - 3; i++)
    {
        if(str[i] == '1' && str[i + 1] == '0' && str[i + 2] == '1')
        {
            found = 1;
            break;
        }
    }

    if(found)
        printf("String Accepted\n");
    else
        printf("String Rejected\n");

    return 0;
}
```

# String Validation for Context-Free Grammar (CFG) S → 0S1 | ε

## 📌 Project Overview

This project implements a **C program** to check whether a given binary string belongs to the language defined by the **Context-Free Grammar (CFG)**:

```
S → 0S1 | ε
```

The grammar generates strings containing an **equal number of `0`s and `1`s**, where all `0`s appear before all `1`s. The program validates the input string and determines whether it belongs to the language generated by the grammar.

---

## 🎯 Aim

To write and execute a C program to check whether a given string belongs to the language defined by the Context-Free Grammar (CFG):

```
S → 0S1 | ε
```

---

## 📖 Theory

Given Grammar:

```
S → 0S1 | ε
```

### Explanation

- The production `S → 0S1` adds one `0` to the beginning and one `1` to the end of the string.
- The production `ε` (epsilon) represents the empty string and serves as the base case.
- Therefore, every valid string generated by the grammar contains:
  - Equal numbers of `0`s and `1`s.
  - All `0`s before all `1`s.

### Language Generated

```
L = { 0ⁿ1ⁿ | n ≥ 0 }
```

### Accepted Strings

- ε
- 01
- 0011
- 000111
- 00001111

### Rejected Strings

- 10
- 0101
- 011
- 00111
- 1100

---

## ⚙️ Algorithm

1. Start the program.
2. Read the input binary string.
3. Count the number of leading `0`s.
4. Count the number of trailing `1`s.
5. Ensure the string contains only `0`s followed by `1`s.
6. Compare the number of `0`s and `1`s.
7. If both counts are equal, accept the string.
8. Otherwise, reject the string.
9. Stop the program.

## 💻 Source Code

```c
#include <stdio.h>
#include <string.h>

int main()
{
    char str[100];
    int i = 0, zero = 0, one = 0, len;

    printf("Enter the binary string: ");
    scanf("%s", str);

    len = strlen(str);

    /* Count leading zeros */
    while(i < len && str[i] == '0')
    {
        zero++;
        i++;
    }

    /* Count trailing ones */
    while(i < len && str[i] == '1')
    {
        one++;
        i++;
    }

    /* Check for invalid pattern */
    if(i != len)
    {
        printf("String Rejected\n");
        return 0;
    }

    if(zero == one)
        printf("String Accepted\n");
    else
        printf("String Rejected\n");

    return 0;
}
```

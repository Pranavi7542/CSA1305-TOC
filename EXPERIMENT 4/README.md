# String Validation for Grammar S → 0A1, A → 0A | 1A | ε

## 📌 Project Overview

This project implements a **C program** to check whether a given string belongs to the grammar:

```
S → 0A1
A → 0A | 1A | ε
```

The grammar generates all binary strings that **start with `0` and end with `1`**, with any combination of `0`s and `1`s in between. The program validates the input string and determines whether it belongs to the language generated by the grammar.

---

## 🎯 Aim

To write and execute a C program to check whether a given string belongs to the grammar:

```
S → 0A1
A → 0A | 1A | ε
```

---

## 📖 Theory

Given Grammar:

```
S → 0A1
A → 0A | 1A | ε
```

### Explanation

- The production `A → 0A | 1A | ε` generates any binary string (including the empty string).
- The production `S → 0A1` requires every valid string to:
  - Start with `0`
  - End with `1`
  - Contain any combination of `0`s and `1`s in between

### Language Generated

```
L = { 0(0|1)*1 }
```

### Accepted Strings

- 01
- 001
- 011
- 0101
- 001101
- 011111

### Rejected Strings

- 10
- 111
- 000
- 1010
- 1
- 0

---

## ⚙️ Algorithm

1. Start the program.
2. Read the input string.
3. Find the length of the string.
4. Check whether the first character is `0`.
5. Check whether the last character is `1`.
6. Verify that all characters are either `0` or `1`.
7. If all conditions are satisfied, accept the string.
8. Otherwise, reject the string.
9. Stop the program.

---

## 💻 Source Code

```c
#include <stdio.h>
#include <string.h>

int main()
{
    char str[100];
    int i, len;

    printf("Enter the string: ");
    scanf("%s", str);

    len = strlen(str);

    if(len < 2)
    {
        printf("String Rejected\n");
        return 0;
    }

    if(str[0] != '0' || str[len-1] != '1')
    {
        printf("String Rejected\n");
        return 0;
    }

    for(i = 0; i < len; i++)
    {
        if(str[i] != '0' && str[i] != '1')
        {
            printf("String Rejected\n");
            return 0;
        }
    }

    printf("String Accepted\n");

    return 0;
}
```

# String Validation for Grammar S → 0S0 | 1S1 | 0 | 1 | ε

## 📌 Project Overview

This project implements a **C program** to check whether a given binary string belongs to the grammar:

```
S → 0S0 | 1S1 | 0 | 1 | ε
```

The grammar generates **all binary palindrome strings**, including the empty string (ε). A palindrome is a string that reads the same from left to right and right to left. The program verifies whether the given input string is a binary palindrome and determines whether it belongs to the language generated by the grammar.

---

## 🎯 Aim

To write and execute a C program to check whether a given string belongs to the grammar:

```
S → 0S0 | 1S1 | 0 | 1 | ε
```

---

## 📖 Theory

Given Grammar:

```
S → 0S0 | 1S1 | 0 | 1 | ε
```

### Explanation

- The productions `0S0` and `1S1` add the same symbol to both ends of the string.
- The productions `0`, `1`, and `ε` are the base cases.
- Therefore, every string generated by this grammar is a **palindrome**.

### Language Generated

```
L = { w | w is a binary palindrome }
```

### Accepted Strings

- ε
- 0
- 1
- 00
- 11
- 010
- 101
- 1001
- 0110
- 011110

### Rejected Strings

- 01
- 10
- 001
- 110
- 1010
- 0101

---

## ⚙️ Algorithm

1. Start the program.
2. Read the binary string.
3. Find the length of the string.
4. Compare the first character with the last character.
5. Continue comparing characters from both ends toward the center.
6. If any pair of characters is different, reject the string.
7. If all corresponding characters match, accept the string.
8. Stop the program.

---

## 💻 Source Code

```c
#include <stdio.h>
#include <string.h>

int main()
{
    char str[100];
    int i, len, flag = 1;

    printf("Enter the binary string: ");
    scanf("%s", str);

    len = strlen(str);

    for(i = 0; i < len / 2; i++)
    {
        if(str[i] != str[len - i - 1])
        {
            flag = 0;
            break;
        }
    }

    if(flag)
        printf("String Accepted\n");
    else
        printf("String Rejected\n");

    return 0;
}
```
